# Unsent: The Micro-Confession Sprint

Entry for the make.fun competition "Unsent: The Micro-Confession Sprint": a
program that writes one micro-confession in exactly two parts to
`/output/entry.txt` — a To: line naming who the message was meant for, then
the unsent message itself on one line, written exactly as it was typed, with
no explanation after it.

The confession is addressed to the pharmacist who counted the tablets each
month: every month for a year they went down the sink while he kept
believing they were working — and wrote that belief into the notes.

## Run

```sh
node main.ts
```

This writes the confession to `/output/entry.txt` (no trailing newline).
